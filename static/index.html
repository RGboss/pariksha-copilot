Database Normalization Rules

1NF: All column attributes are atomic. No repeating groups or multivalued columns.

2NF: In 1NF + No Partial Dependencies (non-prime attributes fully dependent on candidate key).

3NF: In 2NF + No Transitive Dependencies. For every X → A, either X is a superkey or A is a prime attribute.

BCNF: Strict 3NF. For every non-trivial X → A, X MUST be a Super Key.
